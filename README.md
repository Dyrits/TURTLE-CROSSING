# TURTLE-CROSSING

## About The Project

An exploratory project in Python with Turtle, per the original project description: a very basic road crossing game. Move the turtle across the road with the Up and Down keys, avoid the cars, and reach the other side to level up; the cars speed up at each level and the scoreboard tracks your progress.

### Built With

- Python (Turtle)

## Getting Started

### Prerequisites

- Python 3 (Turtle is part of the standard library)

### Running

```sh
python main.py
```
